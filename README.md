# 교사총회 선물 신청 페이지

교사들이 **부서 · 이름**을 입력하고 선물 한 가지를 고르는 신청 페이지입니다.

- 화면: GitHub Pages (정적 페이지)
- DB: 구글 시트 + Google Apps Script (무료, 서버 불필요)
- 선물별 옵션(색상·사이즈), 수량 제한(선택), 품절 처리, 1인 1개(부서+이름 기준), 선물 변경 가능
- 신청 결과는 구글 시트에서 바로 확인 · 엑셀로 내려받기 가능

## 1. 구글 시트 준비 (DB)

1. [sheets.new](https://sheets.new) 로 새 구글 시트를 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 전부 붙여넣고 저장합니다.
4. 상단 함수 선택에서 **`setup`** 을 고르고 **실행** → 권한 요청을 승인합니다.
   시트에 `선물`, `부서`, `설정`, `신청` 탭이 생깁니다.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사합니다.

> `Code.gs` 를 수정하면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영됩니다.
> 시트 내용(선물, 수량, 부서 등)만 바꾸는 것은 재배포 없이 바로 반영됩니다.

## 2. 페이지에 연결

`config.js` 에 복사한 URL을 넣습니다.

```js
window.GIFT_API_URL = 'https://script.google.com/macros/s/.../exec';
```

URL이 비어 있으면 **미리보기 모드**로 동작합니다(실제 저장 안 됨). `index.html` 을 브라우저로 열어 화면만 확인할 때 씁니다.

## 3. GitHub Pages 배포

```bash
gh repo create teacher-gift --public --source=. --push
```

GitHub 저장소 **Settings → Pages → Branch: main / (root)** 로 설정하면
`https://<계정>.github.io/teacher-gift/` 주소가 생깁니다. 이 주소를 교사들에게 공유하세요.

## 4. 운영 방법 (구글 시트에서)

| 탭 | 용도 |
| --- | --- |
| `선물` | ID / 이름 / 설명 / 이미지 / 수량 / 옵션 / 가격. 행을 고치면 페이지에 바로 반영됩니다. |
| `부서` | 부서 선택 목록 |
| `설정` | 제목, 안내문구, 마감(`Y` 로 바꾸면 즉시 종료), 마감일시(`2026-11-24 23:59` 형식, 지나면 자동 종료) |
| `신청` | 신청 내역. 행을 삭제하면 그 수량이 다시 풀립니다. |
| `집계` | 선물·옵션별 신청 수 (자동 계산) |

- **이미지**: `images/` 폴더에 사진을 넣고 `선물` 탭 이미지 칸에 `images/tumbler.jpg` 처럼 적거나, 인터넷 이미지 주소(https://…)를 적습니다. 비워두면 🎁 아이콘이 나옵니다.
- **수량**: 비워두면 무제한, 숫자를 넣으면 선착순으로 그 수만큼만 받습니다.
- **옵션**: 색상·사이즈처럼 고를 것이 있으면 `그레이,베이지,버터` 처럼 쉼표로 구분해 적습니다.
- **가격**: 시트에서만 보이는 값입니다. 스크립트가 이 칸을 읽지 않으므로 신청 페이지에는 나오지 않습니다. 가격·합계는 저장소에 올리지 않습니다(`private/` 는 git 제외).
- **ID** 는 신청 내역과 연결되므로, 신청이 시작된 뒤에는 바꾸지 마세요.
- 남은 수량 = `선물` 탭의 수량 − `신청` 탭에서 해당 선물의 행 개수. (수량을 적은 선물만 표시)

## 참고

- 본인 확인은 부서+이름으로만 합니다. 같은 부서에 동명이인이 있으면 이름 뒤에 구분자를 붙여 달라고 안내하세요(예: 김민수A).
- 동시에 여러 명이 신청해도 Apps Script의 잠금(LockService)으로 수량이 초과되지 않습니다.
